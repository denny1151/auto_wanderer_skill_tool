# 6×6 板塊排列搜尋器

用 Python 搜尋 6×6 棋盤排列，HTML 前端可本機使用，也可部署至 GitHub Pages。瀏覽器透過 Pyodide 執行搜尋；首次搜尋需連線載入 Pyodide CDN。

## 啟動

1. 安裝 Python 3.10 或更新版本。
2. 在此資料夾執行：

   ```powershell
   python server.py
   ```

3. 瀏覽器會開啟 `http://127.0.0.1:8000/`。停止時按 `Ctrl+C`。

## GitHub Pages

推送至 `main` 後，`.github/workflows/pages.yml` 會部署此資料夾根目錄。若 repo 尚未啟用 Pages，先到 GitHub repo 的 **Settings → Pages → Build and deployment → Source** 選 **GitHub Actions**。

可用 `python server.py --port 8080` 指定連接埠，或加上 `--no-browser` 不自動開瀏覽器。

## 設定形狀

- 每行代表棋盤一列；`#` 是板塊格，`.` 是空格。例：`##` 是橫向兩格，`#.` 加換行再加 `##` 是 L 形。
- 每種形狀必須連成一塊，限上下左右相連。
- 可旋轉 0°、90°、180°、270°；不翻轉。
- 主板塊庫存表示可選數量；每個方案恰選一個主板塊。
- 次板塊組可設最低數量、最高數量與「越多越好」。形狀庫存是該組可用總數。
- 次板塊必須至少有一格與主板塊共邊；板塊不可重疊。

## 搜尋優先順序

1. 先滿足各次板塊組的最低與最高數量。勾選「越多越好」的組別，依畫面順序逐組最大化數量。
2. 在次板塊規則最優的排列中，最大化空格數。
3. 空格數相同時，偏好空格連通、最大空格區塊較大、空格區塊數較少。

搜尋有節點上限。若回傳「暫定解」，代表已找到符合數量規則的解，但搜尋未能證明它已是最佳解；可減少形狀種類或庫存後重試。
