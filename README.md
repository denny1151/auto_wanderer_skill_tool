# 6×6 技能排列搜尋器

暗色前端，使用圖形格子編輯主動技能與輔助技能。Python 求解器在瀏覽器透過 Pyodide 執行；首次搜尋需連線載入 Pyodide CDN。

## 使用

- 點「新增主動技能」或「新增輔助技能組」，再點形狀格子編輯技能外形。
- 輔助技能組可設定名稱、顏色、數量上下限與「越多越好」；形狀清單可設各自庫存。
- 點「匯出 JSON」保存目前設定；下次用「匯入 JSON」載入。
- 點「搜尋最佳排列」開始搜尋。

技能可旋轉 90° 倍數，不可翻轉或重疊。每個輔助技能至少一格與主動技能共邊。搜尋優先序：輔助技能規則、剩餘空格數量、空格連通性。多組勾選「越多越好」時，依畫面組別順序比較。

## 本機啟動

安裝 Python 3.10 或更新版本，在此資料夾執行：

```powershell
python server.py
```

瀏覽器會開啟 `http://127.0.0.1:8000/`。停止時按 `Ctrl+C`。可用 `python server.py --port 8080` 指定連接埠，或加上 `--no-browser` 不自動開瀏覽器。

## GitHub Pages

推送至 `main` 後，`.github/workflows/pages.yml` 會自動部署網站。
